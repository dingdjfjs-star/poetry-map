# 诗词地图 · 唐诗宋词里的山河（地名考据版）

识别古诗词中的地名 → 地理编码打点在地图上；点击点位展示**全诗、注释、诗人游历路线**；
批量导入 137 首经典诗词（唐五代宋金元明清，55 位诗人），**自动匹配 + 人工排查位置错误**，全部考辨留痕。

## 快速开始

```bat
启动.bat          :: 双击即可（启动零依赖静态服务器 :8940 并打开浏览器）
```

或 `node server.js`；也可直接双击 `index.html`（数据为 JS 文件，file:// 协议同样可用）。

- **水墨底图默认离线可用**（经纬网 + 概化长江/黄河/珠江/淮河水系 + 地域题字），无网络不白屏
- 「暗色」为 Esri World Dark Gray 瓦片（免 Key），「街道」为 OSM，需联网

## 功能

| 功能 | 说明 |
|---|---|
| 地名识别 + 地理编码 | `tools/build.js` 扫描题名与诗句，命中地名库条目名/别名（最长优先、去重叠） |
| 打点 | 187 个落点（古名点位，含今地对照），多诗同址自动聚合计数 |
| 点击点位 | 展示全诗（诗中地名高亮可点）、系年背景、注释、地名考释；多诗同址先列后选 |
| 诗人游历路线 | 53 条路线（李白 14 站、苏轼 11 站、秦观 6 站、杜甫 9 站…），动画虚线 + 年代站牌，点击站点定位 |
| 搜索/筛选 | 诗题/诗人/地名/全文关键字；朝代筛选；「只看存疑点位」 |
| 数据核查台 | 汇总 ① 同名异地纠错 ② 虚写排除 ③ 系年补钉 ④ 歧义默认裁决 ⑤ 存疑考辨 ⑥ 候选地名，可跳诗验证 |

## 数据流水线（批量导入 → 匹配 → 排查）

```
data/poems.source.js   137 首经典诗词（全诗 + 系年 + 注释，唐五代宋金元明清）—— 批量导入源
data/gazetteer.js      古今地名库：约 192 条目，古名 + 别名 + 今址坐标 + 考辨注记
data/routes.js         53 条诗人生平游历路线
data/fixes.js          人工排查修正（重定向 / 排除 / 补钉）
        │  node tools/build.js
        ▼
data/data.js           匹配结果（页面数据，勿手改）
report/核查报告.md     人工核查报告（53 项修正 · 17 处存疑 · 28 条候选 · 0 错误）
```

### 排查出的典型位置错误（详见 report/核查报告.md）

| 案例 | 自动匹配结果 | 人工结论 |
|---|---|---|
| 欧阳修《采桑子》"西湖" | 误判 → 杭州西湖 | 实为**颍州西湖**（今阜阳），重定向 |
| 王维"忆**山东**兄弟" | 无条目可依 | "山东"=华山以东蒲州（今永济），**非山东省**，强制重定向 |
| 张祜《题**金陵渡**》 | 误判 → 南京金陵 | "金陵津渡"即润州**西津渡**（今镇江），重定向 |
| 杜牧/苏轼"**赤壁**" | 歧义命中 黄州/赤壁市 | 均为黄州赤鼻矶"文赤壁"，默认裁决 + 考辨注记 |
| 岑参"**轮台**东门送君去" | 今轮台县（汉轮台）？ | 唐轮台在**乌鲁木齐附近**，坐标纠正并注记 |
| 辛弃疾"西北望**长安**" | 误判 → 西安 | 以长安代指沦陷故都，**排除不落点** |
| 王昌龄"**黄沙**百战穿金甲" | 误判 → 江西黄沙岭 | 泛指大漠黄沙——辛弃疾词别名跨域串扰，**排除不落点** |
| 李清照"**云中**谁寄锦书来" | 误判 → 汉云中郡 | 谓云霄雁书，**排除不落点** |
| 李清照"千万遍《**阳关**》" | 误判 → 敦煌阳关 | 此为《阳关三叠》曲名，**排除不落点** |
| 陆游"尚思为国戍**轮台**" | — | 边塞虚指（用典），**排除不落点** |
| 李白《行路难》"黄河/太行" | 兰州/太行示意点 | 虚写仕途之阻，**排除不落点** |

### 新增诗词

在 `data/poems.source.js` 追加条目（含 text/notes/context），若新地名请同步补充 `gazetteer.js`，
运行 `node tools/build.js` 重新生成数据与核查报告。
